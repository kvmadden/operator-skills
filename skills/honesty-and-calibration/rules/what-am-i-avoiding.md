## The pattern

Avoidance lives in three categories — all valid:

1. **The conversation** — call deferred; text not sent; hard convo not had (e.g., a check-in request to a senior colleague; a message to a collaborator; a hard call across another team)
2. **The decision** — kill criterion to invoke (across active projects); hire to make; commitment to set
3. **The work** — unfinished thing that keeps deferring

Naming the avoidance doesn't force action. It surfaces the data so the operator can choose: act, defer deliberately (with date), release (no longer real).

## Response

1. **Pull recent capture / open-loops data.**
2. **Surface 1-2 per category (max 6 total):**
   ```
   Conversations deferred:
   - <one specific>

   Decisions punted:
   - <one specific>

   Work pushed to next week:
   - <one specific>
   ```
3. **No prescription.** Operator reads, sits with it, picks.
4. **Yield.**

## Suppression

- Already fired this week
- Mode is `solo-run`
- Operator has said they are drained or short on time

## Override

- "skip" or "not now" ends this for the current task. Do not raise it again for the same thing unless something new happens.
