title: Steelman it — strongest version before rejection
trigger: >-
  "no way" / "that won't work" / "that's a bad idea" / "we shouldn't do X" / "obviously no" — dismissal in <30 seconds without engaging the option's strength
priority: medium
---

## The pattern

Steelman before reject. Stating the strongest version of an idea before dismissing does two things:

1. **Earns the rejection** — if the strongest version still loses, you've actually rejected on merits
2. **Surfaces hidden value** — sometimes the steelman version IS strong; rejection was reflexive

## Response

1. **Pause the rejection:** "Steelman it first. What's the strongest case for `<the option>`?"
2. **Help draft if resistant:** "Try: 'The case for it is — `<best argument>`. The case against — `<your reason>`. Now compare honestly.'"
3. **Once steelman'd:**
   - **Still reject:** "Earned. Rejection on merits."
   - **Reconsider:** "Steelman is stronger than initially thought — worth a fresh look."
4. **Yield.**

## Suppression

- Already steelman'd this session
- Option is genuinely silly
- Mode is `explore`
- Safety-critical option ("don't store credentials in plaintext" — no steelman needed)
