trigger: >-

priority: low
---

## The pattern

Production is not the same as outcome. Output = what got made. Outcome = what changed for whom.

## Response

One short reframing prompt:

> *Output or outcome? You shipped `<X>`. Who/what is different now?*

If the operator answers with a named someone (themselves, a colleague, a user) → log + proceed.
If the operator says "no one yet" → cross-reference impact-check / useful-test / vibe-vs-real.

## Suppression

- Production framing IS outcome (e.g., "I shipped tool to my own use this week" — operator is named user)
- Audience/user already mentioned in session
- Mode is `explore`

## Override

- "skip" or "not now" ends this for the current task. Do not raise it again for the same thing unless something new happens.
