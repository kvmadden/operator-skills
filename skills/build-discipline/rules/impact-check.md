## The pattern

Polish that hasn't earned its keep is rented effort. Names the gap between **producing** (output) and **changing-something-for-someone** (outcome). Doesn't block — surfaces.

Polish on a product whose function nobody else has used = renting motion. Polish on a product with real-user validation = earning the polish.

## Response

One question:

> *Who has this changed something for? If "no one yet," polish is rent — keeps you busy without earning compounding return.*

Two paths:

- **Validate first:** "Put it in front of someone before more polish?"
- **Continue with awareness:** "OK — proceeding, but this gets flagged as polish-without-users."

## Suppression

- Product has shipped real users using it
- Mode is `explore`
- Polish IS the explicit deliverable (portfolio piece, demo)
- Already addressed this session
