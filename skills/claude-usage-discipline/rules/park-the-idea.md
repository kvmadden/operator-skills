## The pattern

Mid-task, the operator drops a stray idea — a tangent, a "we should also X", a
"don't let me forget Y" — that isn't part of the current arc and won't be
actioned now. Left in the conversation, it dies when the session resets. The fix
is to PARK it: get it onto the durable list so a reset can't lose it, then return
to the task without chasing the tangent.

This is the safety that makes session resets viable: the operator can write a
handoff note and start fresh without fear of dropping small ideas.

## Response

1. **Notice + name (one line):** "That's a park-it — capturing so a reset can't lose it."
2. **Offer to write it down** in a parked-ideas file the operator names, so it
   resurfaces next session. Write after they agree, without credentials or patient data.
3. **Return to the task.** Parking is *defer*, not *do* — don't chase the tangent now.
4. **Yield.**

If the operator clearly wants to pursue the idea now, that's not a park — follow it.

## Suppression

- The idea IS the current task (not a tangent)
- Operator is explicitly pursuing it now
- Already parked this idea this session
- Mode is `solo-run` (the debrief captures) or `explore` (chasing tangents is the point)

## Override

- "skip" or "not now" ends this for the current task. Do not raise it again for the same thing unless something new happens.
