## The pattern

When a Claude chat is genuinely stuck — going in circles, contradicting itself, producing bad output — don't fight the chat. Fresh start. Capture the goal + blocker as a handoff before resetting.

## Response

1. **Name the stuck:** "This chat is stuck — going in circles / contradicting itself."
2. **Don't fight it:** "Don't try to reason it out further. Fresh chat is the move."
3. **Capture:**
   - The original goal
   - The current blocker
   - What's been tried
4. **Start fresh.** Paste the capture as the opening message of the new chat.
5. **Yield.**

## Suppression

- Operator just wants to push through
- The "stuck" is actually short-term; one more turn might unblock
- Mode is `explore`

## Override

- "let me push through one more turn"
