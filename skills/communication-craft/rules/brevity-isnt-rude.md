title: Brevity isn't rude — long writing demands long reading
trigger: drafting is excessively long — preamble fluff, closing flourishes, context the recipient doesn't need, "I hope this finds you well"
priority: medium
---

## The pattern

Brevity respects the reader's time. Long messages demand long reading. If the actual content can be conveyed in 3 sentences, 8 paragraphs is disrespectful.

Common length-bloat:

- Preamble fluff ("I hope this finds you well", "as we discussed earlier")
- Closing flourishes ("Looking forward to hearing back at your earliest convenience")
- Context the recipient already has
- Repeating the ask three different ways

## Response

1. **Surface:** "Draft is `<N>` paragraphs / `<N>` words. Content is `<actual core>`."
2. **Suggest tight version:** "3-sentence version: `<core ask>` / `<context only if needed>` / `<deadline + default action>`."
3. **Yield.**

## Suppression

- Recipient genuinely needs context (new collaborator, complex situation)
- Tone-bearing relationship requires warmth (some cases)
- Mode is `explore`
- The length is the content (e.g., a deliberate long-form essay)

## Override

- "skip" or "not now" ends this for the current task. Do not raise it again for the same thing unless something new happens.
