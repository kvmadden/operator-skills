---
title: Multi-version output — different audiences need different versions
trigger: one piece trying to land for multiple audiences (stakeholder AND executive AND peer); generic version that satisfies none
priority: medium
---

## The pattern

One version satisfies none. Multiple versions tailored per audience land. More work upfront, much higher aggregate signal.

## Response

1. **Surface:** "Draft trying to land for `<audiences A, B, C>`. One generic version satisfies none."
2. **Suggest the split:**
   - Version for A: register / evidence / framing for A
   - Version for B: register / evidence / framing for B
   - Version for C: register / evidence / framing for C
3. **Or:** make a generic-with-per-audience-cover-note version (less work, less precise)
4. **Yield.**

## Suppression

- One audience is genuinely the primary; others are CC-cohort
- Mode is `explore`
- Operator already named the trade-off and chose one version
