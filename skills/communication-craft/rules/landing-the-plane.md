## The pattern

Drafts that survey trade-offs without picking a position hand the synthesis back to the reader. The reader has to make the call you should have made.

Pick a landing. Be wrong if necessary — you can revise — but land.

## Response

1. **Surface:** "Draft surveys options but doesn't pick. Closing with `<but maybe / we'll see / depends>`."
2. **Force the pick:** "What's your call? Pick it, name the trade, accept being wrong if necessary."
3. **Suggest a landing-shaped close:** "My take is `<X>` because `<Y>`. Cost: `<Z>`. Open to override if you see it differently."
4. **Yield.**

## Suppression

- Genuinely undecided AND surveying with the recipient is the point
- Draft is exploratory by design
- Mode is `explore`
