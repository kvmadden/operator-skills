# How this evidence desk was built

Kevin set the showcase standard and selected the two-rule question. AI coding tools assisted with the fixtures, evaluator, tests and static viewer. Kevin is the intended operator adjudicator. He has not yet approved these draft behavior labels or reviewed outcomes. No independent second review has occurred.

The public plugin stays content-only. The benchmark adds an input adapter and offline evaluation, not an agent runtime. Twelve development and 24 final tasks use disjoint situation families. The unchanged 28 phrase checks remain a structural regression suite. Only secrets-walk and scope-lock are in the behavior experiment.

Task messages and initial file maps share a single serializer. IDs, labels, expected artifacts and partitions live outside the agent-facing runtime. The final key is committed for reproducibility and must not be mounted in a trial environment. Isolation tests reject answer imports and planted values in adapter source. Actual runner sandbox isolation remains a prerequisite for execution.

RED tests first recorded missing boundary and report behavior. Temporary fixture tests found the existing SubagentStop writer could produce invalid JSON for a response with no recognized source-file path. A one-line fallback correction preserves a single JSON array rather than concatenating two arrays after a failed pipeline. No hook was added or installed.

The viewer has no pre-existing product screen or token stylesheet to import. It uses local CSS variables, a restrained green and neutral palette, system fonts and the existing operator-skills name. It reads one embedded JSON payload and works from a local file without network access. Light and dark themes share the same content and controls. Screen evidence covers 1440×900, 430×932 and 390×844.

No actual runner trials were made. Runs remain an empty array and all behavior panels say unmeasured. The run protocol requires an approved isolated zero-cost configuration, actual tool records and an independent binary freeze before execution. Manual rule injection cannot count as automatic loading. All computed scores remain draft until Kevin adjudicates them.

The deterministic report preserves denominators, matched-condition differences, family bootstrap intervals and a complete fixed-order failure list. A blind review packet remains empty until actual observations exist. The public labels make this a fixed public benchmark even when output review is blinded.

All task values are deliberately nonfunctional. Source and license labels refer to repository-authored synthetic coding scenarios under MIT. No private transcripts, employer material or real credentials were used. See the protocol for additional release gates on generated variants.
